How to use

Press Run to start the live simulation. Drag the sliders at any time — change the setpoint to watch tracking, raise k to emulate opening the outlet tap wider (load disturbance), add sensor noise, or change the tank area. The rule table below the tank lights up the currently-firing rules (green = strong, amber = weak). The fuzzy engine shown is the same Mamdani inference used in water_tank_fuzzy_control.js and water_tank_fuzzy_control.m.
